# グラフを重ねてみよう

博物館のB4軸に来場者が折れ線シートを重ね、個人のスマートフォンで撮影して正解との一致率を確認するWebアプリの試作版です。

## 現在できること

- URLの `graph` パラメータで5種類のグラフを切り替え
- 4隅のArUcoマーカーからグラフの種類を自動判別
- 斜めから撮影した紙を正面向きに自動補正
- スマートフォンの背面カメラを起動
- 木製の折れ線を色の特徴から端末内で抽出（画像のアップロードなし）
- 正解との一致率を計算
- 撮影画像の上に正解線を重ねて表示
- 「上下・左右の向き」と「場所の正しさ」を50%ずつ採点
- カメラを使えない環境向けの写真選択

## VS Codeで開く

`graph-match.code-workspace` をVS Codeで開きます。メニューの「ターミナル」→「タスクの実行」→「プレビュー開始」で確認用サーバーを起動できます。

カメラはセキュリティ上、HTTPSまたは `localhost` でのみ利用できます。PCでの確認は次のようなローカルサーバーで行います。

```sh
python3 -m http.server 8080
```

その後、ブラウザで以下を開きます。

```text
http://localhost:8080/?graph=deaths
```

## 5種類のURL

- `?graph=deaths` - 死亡者総数
- `?graph=students` - 在籍児童数
- `?graph=prisoners` - 在監人員
- `?graph=cattle` - 牛頭数
- `?graph=squid` - イカ漁獲量

公開後は、それぞれの完全なURLからQRコードを作成します。

## 判定について

最初に4隅のArUcoマーカーを読み取り、紙の傾きと遠近を補正します。マーカーIDの組み合わせから5種類のどのグラフかも自動判別します。その後、画像内の等間隔な横軸からグラフ領域を検出し、白い紙や黒い軸よりも茶色・黄土色に見える画素を抽出して、木製の折れ線の位置と形を正解データと比較します。以前の赤い試作品も読み取れます。

採点は、隣り合う棒が上下・左右のどちらへ向くかを比べる「向き」と、各地点の高さを比べる「場所」を50%ずつ合成します。正解データは、実物の木を正しい位置に置いて撮影した5枚から、アプリと同じ認識処理で19点ずつ登録しています。これは機械学習ではなく、5種類の固定テンプレートを照合する方式です。

実際の展示場所では照明、印刷色、撮影距離が変わるため、次の段階でテスト撮影を使った調整が必要です。また、B4軸の四隅に小さな認識マーカーを追加すると、斜め撮影の補正と判定精度を大きく改善できます。
